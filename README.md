# X-ray_Emission_Lines
This code contains the models shown in the thesis paper. Each model is titled properly for easier access.

All parameters are set to the values used in the paper. If you wish to alter them, you may in the following ways:
* For the Sky Model
  * Change the values under the **params** variable
* For the Convolved (Observed) Line
  * Change the value of the **FWHM** variable
* To view only the CXB line
  * In the **Graph of the Sky Model**, replace the **S** with **S_cxb** in the second line
